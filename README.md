# SDK Integration Library

Una librería completa para la integración de múltiples SDKs de servicios de documentos digitales, firma electrónica y validación de identidad.

## 🚀 Características

- **Firma de Documentos**: Integración para firma electrónica con validaciones de identidad
- **Carga de Documentos**: Gestión de documentos para procesos de firma
- **Documentos con Anexos**: Soporte para documentos complejos con archivos adjuntos
- **Validación de Identidad**: Verificación de identidad de usuarios
- **TypeScript**: Completamente tipado para mejor experiencia de desarrollo

## 📦 Instalación

```bash
npm install auco-sdk-integration
```

```bash
yarn add auco-sdk-integration
```

```bash
pnpm add auco-sdk-integration
```

Para ver la documentación de integración de cada SDK visita [docs.auco.ai](docs.auco.ai/sdk/intro)
